# ИНФОГРАФИКА

Брендинг команды **TATARINNOVATION** — вынесен из папок сайта, чтобы рабочие файлы
не смешивались с иконками и спрайтами интерфейса.

```
инфографика/
├── logo-serious.html   лист вариантов: знаки, размеры, лок-апы, палитра
├── make_logo.py        генератор (геометрия в одном месте)
└── логотип/            готовые файлы
```

## Как посмотреть

Открыть `logo-serious.html` двойным щелчком или через сервер:

```
python -m http.server 4181
→ http://127.0.0.1:4181/инфографика/logo-serious.html
```

## Как пересобрать

```
python инфографика/make_logo.py
```

Скрипт сам переходит в свою папку, поэтому запускать можно из корня проекта.

## Что лежит в `логотип/`

| Файл | Что это |
|------|---------|
| `mark-a-green.svg`, `mark-a-blue.svg` | знак A — плитка с монограммой T, два акцента |
| `mark-a-green-512/128/64/32.png` | тот же знак в растре, размеры под аватар и фавикон |
| `mark-b-green.svg`, `mark-b-green-512.png` | знак B — круглая печать |
| `mark-a-mono-ink.svg`, `mark-a-mono-white.svg` | моно-версии для печати и тёмных фонов |
| `lockup-h.svg`, `lockup-v.svg` | горизонтальный и вертикальный лок-апы (для светлого фона) |
| `lockup-h-dark.svg`, `lockup-v-dark.svg` | те же лок-апы для тёмного фона; `-v-dark` стоит на сайте |
| `favicon-32.png` | иконка вкладки |

## Статус

На сайте (блок HI-SCORE, уровень 0) стоит `логотип/lockup-v-dark.svg` — тёмная версия:
светлый текст, плитка с тонкой обводкой. Ссылка идёт из `index.html` напрямую в эту папку.

В шапке сайта (`hud__emblem`) пока остаётся старая пиксельная эмблема
`assets/img/logo-emblem.png` — её можно заменить на `mark-a-green-32.png`,
когда определимся с направлением.

Палитра: графит `#0B1220`, акцент `#22C55E` (зелёный) или `#2F6BFF` (синий),
подписи `#8A93A6`, белый `#FFFFFF`.
