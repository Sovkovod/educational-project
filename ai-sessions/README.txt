Архив ИИ-сессий команды TATARINNOVATION
Проект: сайт-визитка «Волга.ТОП 2026»
=====================================

Допустимые форматы материалов (Приложение 1 к отборочному заданию):
экспорт диалога, PDF, TXT, HTML или снимки экрана.

В каждом файле должны быть видны запрос участника и ответ ИИ — в объёме,
достаточном, чтобы понять, как применялся инструмент.

Состав архива и связь файлов с задачами проекта
-----------------------------------------------

Загриев_Амир/            — дизайн
  01_логотип_и_знак      — знак «A», лок-апы lockup-v / lockup-h и их -dark версии,
                           наборы mark-a-* 32–512 px, favicon-32.png
  02_брендовый_блок      — блок HI-SCORE на уровне 0: компоновка знака, названия
                           и подписи, ширина через clamp(), мобильные правила
  03_пиксель-арт         — скрипт make_assets.py: портреты участников, иконки
                           инвентаря, фон уровня

Галеев_Григорий/         — фронтенд
  01_карточки_участников — data/crew.json: имена, класс, учебная группа под
                           существующий рендер карточек
  02_профиль_участника   — модальное окно профиля: биография, контакт, листание,
                           ловушка фокуса
  03_ссылки_контактов    — разбор contacts.repo / repoLabel: почему «SECRET CODE»
                           вёл не на репозиторий проекта

Сафин_Реаль/             — инфраструктура
  01_запуск_и_контейнер  — почему fetch не работает по file://, демо-режим FALLBACK,
                           Dockerfile и compose.yml, запуск на чистой машине

Зиганшин_Равиль/         — данные и документация
  01_схема_данных        — структура site.json, crew.json, skills.json, scores.json,
                           карта данных DATA-MAP.md
  02_README_по_ТЗ        — ревизия README по пунктам 4.7, 4.11, 5.1 и Приложению 1

Порядок сборки
--------------

1. Положить материалы сессий в папки по участникам (имена файлов — как выше,
   расширение по фактическому формату: .pdf, .txt, .html, .png).
2. Проверить, что в материалах нет паролей, ключей доступа, токенов и персональных
   данных третьих лиц.
3. Собрать архив из содержимого этой папки:

   Compress-Archive -Path .\ai-sessions\* -DestinationPath .\ai-sessions.zip

4. Файл ai-sessions.zip положить в корень репозитория, папку ai-sessions/ удалить.
